# コマ計算機

24fps アニメ制作向けの **秒＋コマ（K）加減算計算機** です。Android スマホを想定した縦画面 PWA で、ホーム画面に追加すればオフラインでも使えます。

## 使い方（概要）

- テンキーの入力は基本 **コマ（K）**
- `S` の直後に押すと直前の数字が **秒**、その後の数字はコマ
- `K` でコマを明示確定
- `6k` / `12k` / `18k` はよく使うコマのショートカット
- `＋` / `−` で現在入力を累積に即反映（メイン＝入力中／サブ＝累積）
- `＝` で総和をメイン表示、サブは消える
- `AC` 全クリア（メインは `0秒＋00K`）／`C` 現在入力のみ／`▶` 1操作戻し
- 上限 `9999秒＋23K`、秒は分に繰り上げません

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで [http://127.0.0.1:43124](http://127.0.0.1:43124) を開きます。

## Android へのインストール（PWA）

1. `npm run build && npm run preview` で配信するか、任意の静的ホスト／同一 Wi-Fi 上の開発サーバを開く
2. Chrome でページを開く
3. メニュー → **ホーム画面に追加** / **アプリをインストール**
4. 一度インストールすれば、オフラインでも起動できます（初回はネットで取得）

> フォント（Zen Maru Gothic Bold）は `public/fonts` に同梱しており、オフラインでも同じ字形で表示されます。

## スクリプト

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバ（ポート 43124） |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果のプレビュー |
| `npm run test:logic` | 計算ロジックのスモークテスト |
